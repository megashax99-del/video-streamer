# Video Streamer (Android)

Android-приложение для отправки выбранного локального видеофайла на RTMP/RTMPS.

## Возможности текущей версии исходников
- выбор видео через системный Android-пикер;
- поле для полного RTMP/RTMPS URL вместе с ключом;
- START / STOP и статус соединения;
- передача видео и аудиодорожки файла;
- отключён повтор файла;
- запрошен AAC bitrate 160 kbps;
- при завершении видеодекодирования приложение останавливает трансляцию.

## Важные ограничения
- Разрешение видео берётся из исходного файла. Принудительное масштабирование в 1080p пока не реализовано.
- Успешная сборка и работа на конкретном телефоне ещё не подтверждены. Нужен запуск GitHub Actions и тест на устройстве.
- Поддержка аудио зависит от наличия аудиодорожки и формата, который декодирует Android.
- Трансляция работает пока приложение активно; отдельный foreground service для гарантированной работы при сворачивании/блокировке экрана пока не добавлен.

## Сборка
Репозиторий использует Android Gradle Plugin 8.7.3, Kotlin 2.0.21, JDK 17 и RootEncoder 2.8.1 (JitPack).
В GitHub откройте вкладку Actions и запустите workflow **Build Android APK**. При успехе APK появится в Artifacts как `Video-Streamer-debug`.

## RTMP URL
Вставьте полный адрес, включая stream key, например:
`rtmp://a.rtmp.youtube.com/live2/ВАШ-КЛЮЧ`
Не публикуйте и никому не отправляйте свой ключ трансляции.
